# Triage Labels

Vocabulary used by the `triage` skill when categorizing and routing issues.
Keep this list canonical — extend it deliberately, not ad hoc.

## Type

- `bug` — defect; something is broken
- `feature` — new capability
- `chore` — maintenance, tooling, build
- `docs` — documentation only
- `question` — needs clarification before work
- `spike` — time-boxed research, no shipped code

## Status

- `pending-triage` — just filed, not yet categorized
- `verified` — reproduced / confirmed real
- `ready` — triaged and ready to work
- `in-progress` — being worked
- `blocked` — waiting on something external
- `done` — resolved

## Role

- `reporter` — filed the issue
- `triager` — categorizes and routes
- `verifier` — confirms resolution
- `griller` — stress-tests the spec / design
