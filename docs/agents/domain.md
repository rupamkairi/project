# Domain Glossary (Ubiquitous Language)

Canonical vocabulary across the ProjectX bounded contexts. Use the
`ubiquitous-language` skill to extend it. When a term is ambiguous, the
definition here wins.

## Contexts

- **Platform / Identity** — actors, organizations, sessions, auth
- **CRM** — customers, leads, deals, pipelines
- **Ecommerce** — products, carts, orders, payments
- **LMS** — courses, lessons, enrollments, instructors
- **Restaurant / Hospitality** — outlets, POS, KDS, tables, reservations
- **ERP** — inventory, suppliers, procurement
- **Workplace** — spaces, desks, bookings
- **Project Management** — projects, tasks, sprints
